# News Application

A Python application that retrieves and displays the latest news articles from an external news API through a simple command-line interface.

## Features

- Fetches the latest news headlines
- Displays article titles and summaries
- Supports multiple news categories (if implemented)
- API integration
- Simple command-line interface
- Error handling for API requests

## Technologies Used

- Python 3
- requests
- News API

## Installation

```bash
git clone https://github.com/PRANJALxDEVxAI/news-app-python.git
cd news-app-python
```

## Usage

```bash
python main.py
```
